显存监视器 · 自签名证书说明
================================

为什么有证书？
  程序没有购买商业代码签名证书，这里用的是一张"自签名"证书，
  用来让 Windows 认出"这个 exe 是谁签的"，从而不再提示"未知发布者"。

已签名的情况
  证书名称：CN=GpuTrayMonitor Self-Signed Code Signing
  有效期  ：2029-11-16
  签名算法：SHA-256（无时间戳）

换到另一台机器怎么用
  1. 把整个"portable"文件夹拷过去（exe + _internal + 本文件夹里的证书和 bat）；
  2. 先双击"install-cert.bat"，把证书导入当前用户的：
       受信任的根证书颁发机构
       受信任的发布者
     （只写当前用户存储，不需要管理员权限，不弹 UAC）
  3. 再双击"GpuMon.exe"，属性→数字签名里能看到上面的签名者。

怎么撤销
  双击"uninstall-cert.bat"，两个存储里的证书都会被删掉，exe 会恢复"未知发布者"。

局限（重要）
  * 自签名只在导入过这张证书的机器上有效；别人拿到 exe 但没导入证书，仍会显示"签名无效"，
    甚至比不签名更显眼。
  * 从网上下载的 exe 带"网络标记"，SmartScreen 仍可能提示"不常见的文件"——那看的是微软的
    云端信誉库，和本机信任链无关。
  * 重新打包 exe 后需要重新签名，命令见项目根目录 README 的「代码签名」一节。

私钥
  build\signing\GpuTrayMonitor-selfsigned.pfx（口令 gputraymonitor）
  不要外传；只需要把 .cer（公钥）发给别人。
